# 磁帶電台 / Tape Radio

一個無需安裝依賴的靜態互動原型。直接在瀏覽器開啟 `index.html`，或以任意本地靜態伺服器啟動即可。

## 已實作

- 24 個通感詞、最多選擇 3 個，並依 Excel 的香調字典轉譯。
- 11 個互斥情緒旋鈕與 0–100% 強度。
- 依「情緒 → 基酒 → 香調交集」取得酒、港樂歌名與風味文案；同分時以強度決定可重現的結果。
- 確認後出帶、點擊或拖放插帶、磁帶齒輪動畫、逐字電台稿和瀏覽器內建語音朗讀。

## 上線前接入項目

目前的電台聲白由本地模板產生，確保原型可以直接試用。正式版可將 `radioText()` 換成後端 API，並將語音改接授權的粵語 TTS 與已取得版權的港樂音訊。
